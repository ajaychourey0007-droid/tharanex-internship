# Thiranex Internship: Full Stack Development

**Intern:** Ajay Chourey (ID: THX-AUG0626-533)

All four tasks are full-stack apps built with HTML, CSS, JavaScript, Node.js/Express and MongoDB.

| # | Task | Folder | Highlights |
|---|------|--------|------------|
| 1 | Personal Portfolio Website | `task1-portfolio` | Projects served from MongoDB, contact form saved to DB |
| 2 | Task Management Application | `task2-task-manager` | JWT auth, per-user CRUD, status filters, responsive |
| 3 | E-Commerce Web Application | `task3-ecommerce` | Catalog, cart, checkout, Admin/User roles, order tracking |
| 4 | Blog Platform with Comments | `task4-blog-platform` | Auth, post CRUD (author only), comments |

## How to run any task
```bash
cd task2-task-manager        # or any other task folder
npm install
cp .env.example .env         # then add MONGODB_URI (and JWT_SECRET where listed)
npm start                    # open http://localhost:3000
```
Each folder has its own README with API details and Render deployment steps.
